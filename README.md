# React + Vite Reviews App

A modern, responsive, React application built with Vite that showcases an interactive review carousel with smooth state transitions, random selection features, and custom styling.

------

## 🌟 Key Features

- **Interactive Carousel:** Navigate forward and backward through individual testimonials seamlessly.
- **Surprise Me Option:** Randomly selects a review while ensuring it doesn't repeat the current view consecutively.
- **Responsive Layout:** Designed to scale gracefully across mobile devices, tablets, and desktop screens.
- **Lighting-fast Tooling:** Powered by Vite and bundled efficiently for high performance.

------


## 🛠 Tech Stack & Tools

- **Frontend Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** CSS3 (with custom CSS variables and responsive design)
- **React Icons:** Font-awesome icons.
- **Linter:** [Oxlint](https://oxc.rs/)

## 🛠 Getting Started Locally

### Prerequisites

Ensure you have **Node.js** (v20+ recommended) installed on your machine.

### Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/my-username/my-repo-name.git
    cd my-repo-name

2. **Install dependencies:**
    ```bash
    npm install

3. **Start the development server:**
    ```bash
    npm run dev

4. **Open in browser:**
    Navigate to http://localhost:5173 to see the app running live.
